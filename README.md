LocalTime ⏰

A simple and responsive digital clock that displays the user's local time in real time.

🚀 Features
Displays the current local time
Updates automatically every second
Simple and clean user interface
Responsive design
🛠️ Technologies Used
HTML5
CSS3
JavaScript
📂 Project Structure
LocalTime/
├── index.html
├── script.js
└── README.md
💻 How to Run
Clone the repository.
Open the project folder.
Open index.html in your browser.
📸 Preview

The clock displays the current local time and updates every second.
